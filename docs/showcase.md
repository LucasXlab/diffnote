# Reproducible CLI showcase

All inputs are synthetic. The installed CLI reads temporary Git history; fixture source and tests are never executed. Nothing is uploaded. This demonstration covers tracked working-tree and staged selection, empty/binary/rename/mode metadata, path/added/deleted review evidence, JSON, Markdown, and configured-filter refusal. It is not an accuracy or security benchmark.

## Sources and transformations

- [showcase.cast](../assets/recording/showcase.cast) is the original local asciinema v2 file, 110 columns × 42 rows. It is not edited or retimed. SHA-256: `8e4b7cce4982d77833da64e6659bd79380fb7dfb54f1d38a5b2ca05caa22bbdb`.
- [showcase.txt](../assets/recording/showcase.txt) concatenates every cast output event, normalizes CRLF to LF, and reduces final blank lines to one final newline. All non-blank output remains; the original cast is unchanged. Actual capture completes rapidly; GIF frames add 8–10 second static reading holds. They do not reproduce original wall-clock speed or simulate typing.
- [panels.json](../assets/recording/panels.json) stores displayed text and source filenames. Working/staged/metadata/signals use complete stdout. The JSON panel selects `source`, `files`, `limits` from the metadata scenario and is explicitly labelled as a projection; the GIF paginates it, while the static PNG shows page 1. Full raw CLI JSON remains in `*-json.json` and `*-json.stdout.txt`.
- The refusal panel contains complete stderr plus an explicitly labelled wrapper check: expected exit 2 and no helper marker. [filter-marker.json](../assets/recording/filter-marker.json) and [commands.json](../assets/recording/commands.json) preserve those outcomes. The added text is not presented as CLI output.
- The social card selects working stdout lines 3–8, 14–15 and its final disclaimer, wrapping without changing words. Native terminal panels add titles, commands, page labels and styling. [render-manifest.json](../assets/recording/render-manifest.json) records reading holds and source cast hash.
- Every command's stdout/stderr is retained, including Git's NUL-delimited metadata. [provenance.json](../assets/recording/provenance.json) records production module hashes. Only the interpreter in command argv is labelled `python`; CLI output paths are unchanged and all are synthetic relative paths. No real private repository or downloaded PR patch enters the assets.

The native SVG logo and five local SVG badges are editable and generated by `scripts/render_assets.py`. Source 0.1.0 is the source version, CI is prepared configuration, and Stars are pending; these are not remote CI, registry, or popularity claims. Menlo/Arial on macOS or DejaVu fonts on Linux are required for rendering; differences in font metrics can change wrapping. The verified render uses macOS fonts and Pillow 13.0.0. Runtime needs neither Pillow nor asciinema.

## Reproduce locally

After the README source installation, use the installed `.venv` interpreter. Install optional tooling in that environment (this step may download public dependencies):

```sh
.venv/bin/python -m pip install 'Pillow==13.0.0' 'asciinema==2.4.0'
PATH="$PWD/.venv/bin:$PATH" .venv/bin/python scripts/record_showcase.py
.venv/bin/python scripts/render_assets.py
```

`record_showcase.py` uses an explicit local `assets/recording/showcase.cast` filename and creates task-owned HOME, XDG_CONFIG_HOME, ASCIINEMA_CONFIG_HOME and TMPDIR. It calls the installed CLI through `showcase.py`, which creates its own synthetic Git repository, minimal environment and fictional contributor. There is no source-import fallback, upload, authentication, model, test execution or runtime network request. Re-recording replaces the old recording and raw result files; preserve a copy if comparing runs. Cast timestamps and event batching may differ, so its hash is not expected to repeat. The renderer verifies every displayed panel against the raw output and the cast before generating media.

For quick functional reproduction without recording or Pillow:

```sh
.venv/bin/python scripts/showcase.py --output assets/recording
```

That command refreshes raw results but not the cast; run the recorder before rendering if those results differ. `scripts/demo.py` remains the small README quick start demonstration. Its earlier `readme-demo.*` assets and notes retain their separate source provenance.
